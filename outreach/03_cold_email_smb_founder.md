# Outreach Script #3 — Cold Email to SMB Founders

**Target:** B2B SaaS founders, 5-50 employees, $100K-5M ARR. Found via:
- ProductHunt launches (last 60 days)
- LinkedIn "founder" + "B2B SaaS" + posted in last 14 days
- IndieHackers milestones page
- BetaList recent launches

**ICP filter:**
1. Founder/CEO (not a marketing manager — they don't have budget authority).
2. ≤ 50 employees (bigger = procurement hell).
3. Has at least one of: pricing page, /careers page, /blog with recent post.
4. Not already using a bot for the same use case (check site for chat widget).

## Sending rules

- **Volume**: 30/day, never more. Spread across the workday.
- **From**: your real email (ghdejr11@gmail.com) — not a separate domain.
  Cold-email warmup tools = scam-flagged anyway in 2026. Real address > "deliverability hacks".
- **Banned**: "!", "just", "wanted to", "I hope this finds you", "circling back", "quick call".
- **CAN-SPAM**: include physical address in footer (your business registration address is fine).
- **GDPR**: if leads are EU-based, only contact those publicly-known professional emails (CEO, founder@ etc).
- **Follow-up**: max 2 follow-ups. After that → archive.
